# Libft

## Description

Libft is a C library that reimplements selected standard-library functions and provides additional string, output, and linked-list utilities. It is intended to help build a reusable foundation for later C projects.

## Instructions

Run `make` to compile the sources and create `libft.a` in the repository root. Use `make clean` to remove object files, `make fclean` to remove object files and the library, and `make re` to rebuild. The project uses `cc -Wall -Wextra -Werror` and `ar`.

## Resources

## Library details

The library includes character checks and conversions, memory functions, string functions, allocation helpers, file-descriptor output functions, and linked-list operations. Linked-list functions include node creation, front/back insertion, iteration, deletion, size/last lookup, clearing, and mapping.
